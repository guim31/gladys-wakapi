# Changelog

All notable changes to this integration are documented in this file. The format
follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project
uses [semantic versioning](https://semver.org/).

Describe each change under `## [Unreleased]` as you make it. The Release
workflow moves that section under the version it ships, and the section becomes
the notes of the version's GitHub Release.

## [Unreleased]

### Added

- Wakapi (self-hosted or wakapi.dev) and WakaTime in Gladys: a "Wakapi
  <name>" device with the coding time today, this week and the daily average
  over the last 7 days, and the main project and language of the day.
- Scene triggers "First coding of the day" and "Daily coding goal reached"
  (goal set in the configuration), and the scene action "Read today's coding
  time" (a sentence and the figures, for a message or a voice announcement).
- Dashboard widget "Coding time": today, the week, a gauge of the daily goal,
  a bar chart of the last 7 days and today's projects, each block but today
  can be hidden.
- Texts and documentation in English, French, German and Spanish.
